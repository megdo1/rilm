## 🚀 Comment Tester

### Option 1 : Connexion Rapide (Recommandé)
1. Sur la page de connexion, repérez la carte **"🧪 Comptes de Test"**
2. Choisissez le profil que vous voulez tester
3. Cliquez sur le bouton **"⚡ Connexion"** correspondant
4. Vous serez connecté immédiatement

### Option 2 : Connexion Manuelle
1. Allez sur l'onglet **"Connexion"**
2. Entrez l'email et le mot de passe du compte désiré
3. Cliquez sur **"Se connecter"**

### Option 3 : Créer votre propre compte
1. Allez sur l'onglet **"Inscription"**
2. Remplissez le formulaire avec vos informations
3. Sélectionnez votre profil
4. Créez votre compte

---

## ⚠️ Première Connexion

Si un compte de test n'existe pas encore dans la base de données :
1. Allez dans l'onglet **"Inscription"**
2. Utilisez exactement les identifiants indiqués ci-dessus
3. Choisissez le nom qui vous convient
4. Sélectionnez le rôle correspondant
5. Créez le compte

Une fois créé, le bouton de connexion rapide fonctionnera pour ce profil.

## 🔄 Tests Multi-Utilisateurs

Vous pouvez tester plusieurs profils en même temps :
1. Ouvrez **plusieurs navigateurs différents** (Chrome, Firefox, Safari, etc.)
2. OU utilisez des **fenêtres de navigation privée**
3. Connectez chaque fenêtre avec un compte différent
4. Testez les interactions entre utilisateurs
